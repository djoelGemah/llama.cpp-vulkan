# Qwen Vulkan Installer

Automatic installer for llama.cpp + Vulkan + Qwen3.6 35B.

## Installation

```bash
git clone https://github.com/NAMAUSER/qwen-vulkan-installer.git
cd qwen-vulkan-installer
chmod +x install.sh
./install.sh
```
