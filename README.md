# Qwen Vulkan Installer

Automatic installer for llama.cpp + Vulkan + Qwen3.6.

# Requirements
- Ubuntu 24.04
- AMD GPU dengan Vulkan
- Internet
- Minimal 50 GB ruang kosong


## Installation

```bash
git clone https://github.com/djoelGemah/llama.cpp-vulkan.git
cd llama.cpp-vulkan

chmod +x install.sh

./install.sh
```
